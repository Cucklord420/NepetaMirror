# Licensing scope

Reviewed 10-17-2026.

The existing [LICENSE.md](LICENSE.md) contains an MIT notice naming Google, Inc. and AngularJS. That notice is preserved. It does not establish that every mirrored package, depiction, image, or asset in this repository is owned by the repository owner or shares that license.

Mirrored packages and third-party materials retain their respective terms. No blanket AGPL grant is made for them, and missing package licensing is not treated as permission to relicense.

Future original additions controlled by Cucklord420 should be clearly marked AGPL-3.0-only when they are added. Existing MIT permissions remain available for material already distributed under that grant.

The Rust mirror verifier is an original addition marked `AGPL-3.0-only` in its Cargo manifest. That scope does not extend to the inherited package archives, indexes, depictions, images, or other third-party material.
